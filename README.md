# Instrument That

The that-app home for live measuring instruments.

## Purpose

Instrument That is the console / cassette surface where measuring tools live. Instruments mount, morph with pixel morph, and are gated by the Valid Intent 90% gate and Automata's Graceful Gate.

## First Instrument

**GitMore Heatmap** — thermal calendar of forge activity. Cassette source: `act-v4/cassettes/gitmore-heatmap.md` (CCK-CASSETTE-GITMORE-HEATMAP-0001).
